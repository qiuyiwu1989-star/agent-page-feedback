任务中心 团队内部

网站上的每一条意见都是一张任务卡：人负责提出和拍板，agent 负责分诊、出方案、修改和交付报告。所有讨论、决定和修改都记在卡片上，「时间线」可以复盘全过程。

  1. 在页面上提出打开任意页面，点左下角「批注」，再点要改的地方，自动附位置截图。
  2. agent 分诊明确的写清打算怎么改；不确定的出 A / B 方案，附预览链接。
  3. 负责人拍板用管理员通行码登录的人点「可以做」或「选 A / B」，这就是 agent 的执行信号。
  4. agent 交付改完附交付报告：改了什么、为什么、改前 / 改后截图、回滚编号。
  5. 负责人验收点「通过」完成；「再改」写明意见；「改回来」恢复原样。

新建需求

不依附页面位置的需求，例如「重建首页生成器」。写清「怎么算做完」，负责方会照着交付、别人照着核对。
